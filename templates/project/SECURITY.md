# Security policy

Project maintainers must document supported application versions, a private
vulnerability reporting channel and their expected response process here before
publishing the application. No project security contact has been configured.

Do not send application vulnerabilities to the starter's maintainers. Avoid
posting credentials or exploitable details publicly. Local secret checks are
part of the Git hooks; follow [Contributing](CONTRIBUTING.md) and configure the
project's own security review and response process.
